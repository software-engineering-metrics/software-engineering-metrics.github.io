# Examples

Small, concrete examples that show the book's ideas in use. These are
illustrative, not exhaustive. The full templates live in the appendices
([chapter 9.4, Templates](../chapters/09-04-templates.md)).

## Contents

- **[metrics-charter-example.md](metrics-charter-example.md)** : a filled-in
  metrics charter, the kind described in
  [chapter 1.4](../chapters/01-04-metrics-governance-and-ownership.md).
- **[dashboard-spec-example.md](dashboard-spec-example.md)** : a worked
  dashboard specification for a delivery-metrics dashboard, following
  [chapter 8.1](../chapters/08-01-designing-an-engineering-metrics-dashboard.md).
- **Chapter skeleton** : to start a new chapter, copy the
  [chapter template](../contributing/chapter-template.md).

## Using these

Copy an example, replace the content with your own, and keep the shape. The
point is the structure and the level of detail, not the specific values.
